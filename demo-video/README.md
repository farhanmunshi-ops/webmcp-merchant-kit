# Programmatic demo video

The submission video was not filmed — it was **generated by code**, on brand for an
agentic-commerce entry: `record.mjs` drives the live store's real WebMCP tools in a
headless Chromium (Playwright) while recording 1080p scenes; `narrate.mjs` voices the
script with an audio-out LLM; `assemble.mjs` adds eased push-in zooms, stat callouts,
and freeze-padding, then concatenates (ffmpeg-static).

```bash
npm i playwright ffmpeg-static && npx playwright install chromium
node record.mjs && OPENAI_API_KEY=… node narrate.mjs && node assemble.mjs
```
Every frame is the real product — the polyfill injects the same `document.modelContext`
API an agent-capable browser provides, and the tools do their real work.
